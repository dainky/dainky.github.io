# Dainky Games developer website

Static developer/support website for Tree Inc. GitHub Pages serves `main` at the repository root: https://dainky.github.io/.

`app-ads.txt` contains the Google AdMob authorized-seller entry copied from the publisher account. Keep it at https://dainky.github.io/app-ads.txt.

The reviewed privacy policy remains in the separate existing repository at https://dainky.github.io/tree-inc-privacy/. This site has no JavaScript, analytics, advertising or cookies.
